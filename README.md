# Smart City Mobility Analytics

SQL project using MySQL with 10,000+ simulated ride records across Indian cities.
**Files**
- `smart_city_schema.sql` — create DB & tables
- `smart_city_seed_data.sql` — insert sample data
- `analysis_queries.sql` — core analytics queries
- `advanced_queries.sql` — optional advanced queries

## How to run
1. Open MySQL Workbench
2. Run `smart_city_schema.sql`
3. Run `smart_city_seed_data.sql`
4. Run `analysis_queries.sql` and explore results
